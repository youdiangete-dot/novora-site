# NOVORA Agent 53A Internal AI Sketch Draft Pipeline Plan

## Purpose And Role

Agent 53A defines a future internal AI sketch draft pipeline plan for NOVORA.
It sits after the Agent 50A, Agent 50B, and Agent 50C structured-input
planning work.

Agent 53A is:

- Internal planning only.
- A docs-only pipeline contract.
- A future implementation guide for review, generation, retry, cost, storage,
  and delivery boundaries.
- A reminder that internal AI sketch drafts are concept sketches only.

Agent 53A is not:

- An implementation.
- A model call.
- Image generation.
- An API route.
- A server action.
- A Supabase migration.
- Customer-facing UI.
- Email or customer delivery.
- CAD, a quote, an order, or production approval.

No image is generated by this planning task. No OpenAI, image provider, storage
provider, email provider, or other external service is called or connected.

## Relationship To Agent 50A, 50B, And 50C

The locked future sequence remains:

```text
Customer Concept Brief -> Design Spec JSON -> Hand Sketch Instruction -> future internal AI sketch draft workflow
```

Agent 50A defines Design Spec JSON Schema v1, the canonical internal structured
design specification that sits between a customer Concept Brief and later
sketch work.

Agent 50B defines Hand Sketch Instruction Template v1, the fixed internal
instruction generated from Design Spec JSON before any internal draft workflow.

Agent 50C defines how future work should transform existing Concept Brief data
into Agent 50A Design Spec JSON before Agent 50B instruction generation.

Agent 53A plans the future internal draft pipeline after those layers. It does
not replace Agent 50A, Agent 50B, or Agent 50C. It does not use raw customer
brief text directly as a generation prompt. It does not implement OpenAI,
image generation, prompt execution, storage writes, admin UI, or customer
delivery.

## Proposed Future Pipeline Stages

These stages describe a possible future workflow only. Agent 53A does not
implement any stage.

1. Concept Brief intake already exists.
2. Concept Brief to Design Spec JSON using a future implementation based on
   Agent 50C.
3. Design Spec JSON validation against Agent 50A planning rules.
4. Design Spec JSON to Hand Sketch Instruction using a future implementation
   based on Agent 50B.
5. Human/admin pre-generation review gate for the Design Spec and Hand Sketch
   Instruction.
6. Future internal-only image generation job creation, if separately approved.
7. Internal draft output storage planning, if separately approved.
8. Admin-only draft review.
9. Revision prompt or redraw loop planning.
10. Human final approval for customer.
11. Customer delivery remains email-only after human approval and must be
    separately planned.

The pipeline must keep internal drafts hidden from customer pages until a
separate delivery workflow is approved and a human-reviewed output is approved
for customer delivery.

- Generation tier placeholder.

Any future forwarding of reference images or image-derived data to an external

- Prompt version metadata.
- Template version metadata.
- Design Spec schema version metadata.
- Cost estimate metadata.

Future outputs must not imply:

- Automatic approval.
- Automatic email delivery.

- CAD approval.
- Quote approval.
- Order creation.
- Production approval.

AI generation success alone must never approve a sketch. A generated output can

## Internal-Only Generation Policy

AI draft output is internal only. Drafts must be hidden from customer pages,
public URLs, public galleries, and automated customer delivery.

Required policy rules:

- Customer submits a Concept Brief before sketch work begins.
- GPT or an image model can generate internal drafts only.
- GPT may assist revision prompts or redraw direction only inside an internal
  workflow.
- Drafts must be reviewed by a human.
- Drafts may need revision or redraw.
- Human final approval is required before customer delivery.
- `approved_for_customer` is not equal to `approved_for_gallery`.
- AI generation success does not equal approval.
- Failed generation does not block the Concept Brief workflow.
- No automatic paid customer-facing generation is added in this docs-only
  phase.

Final legal AI sketch review statuses remain only:

- `internal_draft_not_generated`
- `draft_generated_internal_only`
- `needs_revision`
- `approved_for_customer`

`pending` is illegal, excluded, and not valid for final AI sketch review
status.

## Human Review Gates

The future workflow must include these human gates:

- Pre-generation review of Design Spec JSON and Hand Sketch Instruction.
- Post-generation review of draft output.
- Revision decision when a draft is unsafe, unusable, mismatched, or unclear.
- Final approval for customer delivery.
- Separate gallery approval if public gallery use is ever added later.

Gallery approval is not part of Agent 53A. `approved_for_customer` must not be
treated as `approved_for_gallery`, public publishing consent, or marketing use.

## Error, Failure, And Retry Planning

Future implementation should plan safe handling for:

- Malformed Design Spec JSON.
- Invalid Hand Sketch Instruction.
- Missing required fields.
- Unsupported piece type or material.
- Risky reference image request.
- Provider failure.
- Timeout.
- Cost limit exceeded.
- Unsafe or unusable draft.
- Mismatched sketch structure.
- Duplicate job attempt.
- Retry cap.
- Manual review fallback.

Agent 53A does not implement retry logic. Future retry behavior should be
bounded by a retry cap, idempotency key, cost guard, and human-visible failure
state. A failed generation should not erase the submitted Concept Brief, should
not show customer-facing success for a sketch, and should not block normal
studio follow-up.
